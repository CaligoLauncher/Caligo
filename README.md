# Caligo — GPUI, шаг 2

Небольшая нативная оболочка на Rust / GPUI 0.2.2:
- Панель **слева** с «Главная» и «Настройки», встроенный Manrope.
- Главная пока пустая, кроме выбранного фона.
- «Настройки → Оформление»: предпросмотр, выбор PNG/JPEG через системный диалог,
  сброс к стандартному фону, автоматическое сохранение и восстановление.
- Системная строка заголовка Windows, не нарисованные в GPUI кнопки.
- Окно 1000×620, минимум 720×440; настройки прокручиваются в небольшом окне.
- Tab / Shift+Tab, Enter / Space; состояния наведения, нажатия и занятости.
- Закрытие последнего окна завершает приложение.

**Запуск Minecraft, сборки, вход, скин, редактор и плагины не возвращены.**
Blur / Liquid Glass, видеообои и анимации не добавлены.

## Обои и данные

Выбранная картинка проверяется и сохраняется отдельной PNG-копией:
- Windows: `%APPDATA%\.caligo\gpui\wallpaper.png`
- Linux: `$XDG_CONFIG_HOME/caligo/gpui/wallpaper.png` либо
  `$HOME/.config/caligo/gpui/wallpaper.png`.

Исходный файл не меняется и после выбора не требуется.
Старые игровые данные, `interface-*`, `shell-*` и прежние обои не читаются,
не мигрируются и не удаляются. «Сбросить фон» удаляет **только** новую копию.

Чтение, декодирование, уменьшение и запись идут на background executor, не
в render. Пока операция выполняется, повторные действия заблокированы.
Отмена диалога не меняет фон; ошибка выбора/записи сохраняет предыдущий фон.
Ошибка восстановления показывается в настройках, повреждённый файл сам не удаляется.

Ограничения: PNG/JPEG, 32 МБ, 8192 px по стороне, 32 мегапикселя.
Изображение уменьшается с сохранением пропорций до 2560×1440; оригинал не
увеличивается. Отображение — cover: без растягивания, с обрезкой краёв.
Используется один статический кадр, не анимация PNG.
Копия заменяется через временный файл в том же каталоге; это не гарантия
сохранности при любом аппаратном сбое. Несколько одновременно запущенных
экземпляров не синхронизируют превью: на диске побеждает последняя запись.

При замене/сбросе старая картинка удаляется из GPUI sprite atlas.
Это не измерение общего RAM/VRAM/CPU/GPU и не гарантия бюджета 200 МБ.

## Нативный заголовок Windows

`TitlebarOptions.appears_transparent = false` оставляет системные non-client
layout и hit testing. Однако GPUI 0.2.2 не добавляет `WS_CAPTION` при создании
обычного окна. Маленький модуль `native_window` добавляет этот флаг, сохраняя
остальные стили, и вызывает пересчёт рамки через Win32 `SWP_FRAMECHANGED`.

Вызов выполняется на UI executor **вне активного заимствования App/Window**:
изменение рамки может синхронно вызвать callbacks изменения размера.
Caligo не рисует caption-кнопки, не подменяет WndProc и не ставит input hooks.
Цвет и оформление строки определяет Windows.

Нужно проверить нативно: перетаскивание, двойной щелчок, сворачивание,
максимизация/восстановление, закрытие, Alt+Space и DPI.

## Сборка в Windows

Нужны актуальный Rust stable MSVC, Visual Studio C++ Build Tools и Windows SDK.

```sh
cargo run
cargo test
```

Для оптимизированной сборки:

```sh
cargo run --release
```

GPUI 0.2.2 в release компилирует HLSL через `fxc.exe` из Windows SDK.
При необходимости задайте `GPUI_FXC_PATH`. Это инструмент сборки, не условие
запуска готового приложения. Первая компиляция не равна времени старта окна.

## Проверки

```sh
cargo check --all-targets
cargo test
```

Тесты: навигация, сохранение/восстановление/замена/сброс, сохранность исходников
и старых данных, ошибочные файлы и запись, лимиты, уменьшение и порядок BGRA.

Существующий GitHub workflow не изменён. Для Linux GPUI X11 линковка требует
`libxkbcommon-x11-dev` в дополнение к уже установленным библиотекам.
Если CI сообщает `unable to find library -lxkbcommon-x11`, тесты **не запускались**.
Исправление списка системных пакетов workflow требует прав владельца.

CI на Ubuntu не доказывает Windows-сборку, внешний вид, системный диалог,
DPI и работу кнопок titlebar. Память, CPU/GPU и startup пока не измерены.

## Ручной чек-лист

1. Открыть настройки; выбрать PNG/JPEG с кириллическим именем.
2. Вернуться на главную: фон должен заполнить клиентскую область.
3. Перезапустить: фон восстановился; перемещение оригинала не мешает.
4. Выбрать другой файл, отменить выбор, выбрать повреждённый/слишком большой:
   отмена и ошибки не должны сбрасывать предыдущие обои.
5. Сбросить фон и перезапустить: стандартный фон остаётся.
6. Проверить Tab/Shift+Tab/Enter/Space и прокрутку на 720×440.
7. Проверить штатные Windows-кнопки, drag, double click, Alt+Space и 125/150% DPI.

Шрифт Manrope и лицензия OFL сохранены в `assets/fonts`.
